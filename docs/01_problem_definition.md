# Problem Definition

The project tests a contract extraction workflow that must not guess missing terms, silently repair corrupted OCR, choose between unresolved contradictions, infer governing law from addresses, or treat unrelated monetary amounts as liability caps.

Requested fields: agreement title, party names, effective date, payment terms, automatic renewal terms, termination notice period, governing law, and liability cap.

Allowed evidence states: SUPPORTED, MISSING, AMBIGUOUS, CONFLICTING, UNREADABLE.
