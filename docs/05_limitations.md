# Limitations

Synthetic contracts only.

Small benchmark sizes.

Controlled conversational model runs rather than independent API executions.

No real OCR pipeline, scanned documents, production deployment, latency, cost, privacy, monitoring, or throughput measurements.

Evidence was manually inspected rather than checked by a deployed provenance validator.

Prompt injection cases are controlled tests, not a security proof.

No legal correctness or enforceability claim is made.
